- `SRS-College-Academic-AI-Platform-v1_0-FINAL.md`: System Requirements Specification (SRS v1.0).

This repository is governed by the autonomous SDLC multi-agent framework defined in the root `AGENTS.md`. All documentation updates, schema revisions, and architecture changes undergo the standard Issue -> Isolated Worktree -> TDD / Validation -> PR Review -> Squash Merge lifecycle.
